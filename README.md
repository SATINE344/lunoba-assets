# lunoba-assets

Archivos estáticos públicos de **lunobahome.com** (Lunoba Home). Los escribe el flujo de n8n
"[LUNOBA] Banners IA" y los lee el theme de la tienda por `raw.githubusercontent.com`.

- `banner.json`: los banners del hero que están en vivo (`slides` vacío = el theme usa el banner estático).
- `banner.prev.json`: la versión anterior, para volver atrás.
- `hero/`: imágenes finales (webp, computadora 1920x1088 y celular 1088x1360).
- `previews/`: vistas previas chicas que muestra el formulario de n8n (se pueden borrar).

No editar a mano: lo pisa el flujo.
